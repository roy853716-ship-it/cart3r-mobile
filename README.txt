CART3R MOBILE — iPhone Safari web app
=====================================

CONTENTS
- index.html: complete responsive app
- manifest.webmanifest: installable web-app metadata
- sw.js: basic offline caching
- icon-192.png / icon-512.png: app icons

FEATURES
- Mobile Lua text editor
- Copy code to clipboard
- Save, load, delete and export snippets
- Local activity console
- Black/crimson mobile interface
- Home Screen / PWA support

IMPORTANT LIMITATION
This is a standalone coding workspace, not a Roblox executor. It does not inject code into Roblox, bypass bans, or run code in DEGRADE or other live games. Use Roblox Studio to test scripts in experiences you own or are authorized to edit.

HOW TO PUT IT ON YOUR IPHONE
1. Upload the contents of this folder to a static HTTPS host (for example, a static site host).
2. Open the published HTTPS address in Safari on your iPhone.
3. Tap Share, then Add to Home Screen.
4. Enable "Open as Web App" if iOS shows that option, then tap Add.

LOCAL PREVIEW
Open index.html in a browser. Some install/offline features require HTTPS hosting.
